Lime Music App

经典简洁 UI

App 不追液态玻璃，界面更直：列表、播放、返回。 重点是稳、轻、少打扰。手机上用起来应该像工具，不像展台。

  • ✓ 完美适配安卓：各版本机型深度适配，界面与交互流畅一致。
  • ✓ 稳定无闪退：长时间播放、后台运行均经过实测。
  • ✓ 无广告：全程零广告、零弹窗打扰。
  • ✓ 无 VIP：全部功能免费开放，不区分会员。
  • ✓ 支持后台播放：锁屏、切到其他应用，歌会继续播。
  • ✓ 支持本地音乐与仓库音乐，来源自由切换。

1. 部署

把播放器部署到 GitHub Pages，或任意静态托管。

2. 放歌

在 music 仓库里丢音频文件，文件名就是歌名，自动识别。

3. manifest

可选。填上歌手名，播放器会显示。

4. 换背景

背景图也从 music 仓库取，找不到就降级成 CSS 渐变。
